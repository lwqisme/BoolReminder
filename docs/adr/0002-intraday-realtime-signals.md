# 盘中信号 + 实时价替代盘后日线信号

信号调度从盘后日线（每晚 23:00 上海时间，用前一日收盘价）改为盘中实时（美东 11:00 和 12:00，用 Longbridge 实时报价追加/替换日线最后一天）。

**决策**：盘中定时信号替代晚间定时。信号生成时，通过 `quote_ctx.quote()` 获取实时成交价，追加到日线序列末尾作为最后一天（若日线已有今天则替换）。休市跳过。dry-run 和定时信号共用同一套实时价逻辑。

### 取舍

- **选实时价**：盘中信号能捕捉当日盘中突破，比盘后日线领先一个交易日。代价是实时价仅一个成交价（无 OHLC），且依赖 Longbridge API 在盘中可用
- **选 11:00/12:00 ET 两发**：比每 30 分钟少噪音，比仅收盘发更及时。权衡了信号频率和邮件干扰
- **不选保留晚间定时 + 新增盘中**：两套定时会重复发信，且晚间日线在盘中实时价面前已无增量价值

### 后果

- 信号可能在盘中出现又消失（布林带随实时价浮动），用户需接受这种非确定性行为
- 盘中 API 故障需发邮件通知（静默失败不可接受）
- 晚间 cron 移除，减少运维点
