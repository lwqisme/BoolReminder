# LEAPS 模拟结果包含未完成交易

参数实验室的 LEAPS 预设模拟（`/api/strategy-lab/parameter-lab/leaps-simulate`）原先只返回已完成至少一档卖出的交易——最近期的入口信号（数据不足以到达最低持有天数）被静默丢弃。这与信号 dryrun 的行为不一致：dryrun 会报告当前日的入口信号，而模拟完全看不到它。

**决策**：`run_leaps_simulation` 不再跳过数据不足以完成最低持有期的入口。改为用 `allow_open=True` 调用 `compute_sell_ladder`，让数据耗尽的交易标记 `open_pct`（未卖出比例）和 `unrealized_roi_pct`（未实现回报率）而非强制平仓。前端对 `open_pct > 0` 的交易用独立视觉标记（蓝色菱形/空心标记 + "持仓中"文字）区分于已完成的交易。

**拒绝的替代方案**：新增一个专门的"信号预览" endpoint 与模拟分离。理由——两者本质是同一计算逻辑应用到不同数据窗口，分离会导致两条路径的卖出阶梯算法再次分歧（已发生过一次：ADR-0001 统一了卖出引擎）。

**后果**：
- GA 评测路径不受影响（`allow_open=False` 不变）
- 模拟返回结构不变，仅 `trade_details` 中可能多出 `open_pct > 0` 的条目
- 日期间隔短（数据不足一个完整卖出周期）时，模拟结果中"持仓中"交易比例会明显升高——这是正确行为
